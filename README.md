# Solar Panel Fault Classification using KNN

A complete engineering AIML project with a Jupyter Notebook backend and Streamlit GUI.

## Important dataset note
The included dataset is self-generated synthetic educational data (6,000 base observations, six classes, 10 numeric features plus one categorical feature). It contains intentionally injected missing values, outlier-like values and duplicate rows to demonstrate data-quality handling. It is **not real field data** and must not be used for safety-critical decisions. Dataset provenance and generator are in `data/DATASET_SOURCE.txt` and `src/generate_dataset.py`.

## Project structure
- `data/solar_pv_faults_synthetic.csv` — included dataset
- `src/generate_dataset.py` — reproducible dataset generator
- `src/ml_backend.py` — preprocessing and training utilities
- `notebooks/solar_panel_fault_knn.ipynb` — full notebook workflow
- `train_model.py` — train, tune, evaluate and save artifacts
- `app.py` — interactive Streamlit GUI
- `models/` — trained model and metadata generated after training
- `reports/Project_Report.docx` and `reports/project_report.md` — report
- `reports/figures/` — evaluation plots generated by training

```bash
python3 -m venv .venv

```

## Train the model
From the project root:
```bash
python train_model.py
```
This runs stratified 5-fold GridSearchCV on the training split, evaluates once on the held-out test split, and saves the fitted pipeline, metadata, and plots. The parameter search may take a few minutes.

For a faster smoke test, edit `train_model.py` to pass `run_grid_search=False` to `train_and_evaluate`; use the full grid search for the final report.

## Run the Jupyter Notebook
```bash
jupyter notebook
```
Open `notebooks/solar_panel_fault_knn.ipynb` and run cells in order. The notebook is the complete ML implementation and records actual metrics from your environment.

## Run Streamlit
After training:
```bash
streamlit run app.py
```
Open the local URL printed by Streamlit (normally http://localhost:8501).

## GUI features
1. Dashboard with saved test metrics and model parameters
2. Single-record prediction using user-entered measurements
3. Batch CSV prediction and downloadable results
4. Evaluation metrics, confusion matrix and performance plots
5. Dataset explorer and dataset download

## Model methodology
- Duplicate removal and missing-target removal
- Numeric median imputation, IQR-based outlier clipping, standardization
- Categorical imputation and one-hot encoding
- Mutual-information feature selection
- KNN hyperparameter search (K, distance weighting, Minkowski p)
- Stratified 80/20 train/test split and stratified 5-fold CV on training data
- Accuracy, balanced accuracy, macro precision/recall/F1, weighted F1, MCC and confusion matrix

## Reproducibility and limitations
Random seed 42 is used for dataset generation and splitting. Results can vary slightly with library versions. Synthetic-data accuracy is not a claim of field performance. Do not use the output for equipment protection or maintenance decisions without validation on real independent data.
